# Wordstat MCP

Отдельный MCP-сервер для сайта Яндекс Wordstat и поисковых подсказок Яндекса. Не использует Яндекс Облако. MCP работает по Streamable HTTP; результаты возвращаются напрямую, без базы данных и истории.

## Запуск контейнера

Из корня Avadge-Web:

```bash
docker compose build wordstat-mcp
docker compose up -d wordstat-mcp
```

Адрес с компьютера: `http://127.0.0.1:8091/mcp`; из других контейнеров сети Compose: `http://wordstat-mcp:8091/mcp`. Порт опубликован только на localhost. Для доступа с другого устройства нужен защищённый прокси с ограничением доступа.

## Cookie

Для Wordstat нужен браузерный `Session_id`. Получение описано в [YANDEX_COOKIE_GUIDE.md](YANDEX_COOKIE_GUIDE.md). Передать его можно одним из способов:

- Переменной `YANDEX_SESSION_ID` окружения Compose (или в корневом `.env` Compose) перед запуском контейнера.
- Заголовком `X-Yandex-Cookie` при каждом вызове инструмента: значение `Session_id` либо полная строка `Session_id=...; ...`. Также принимается стандартный заголовок `Cookie`.

Заголовок имеет приоритет над переменной окружения. В Streamable HTTP его нужно передавать на каждом HTTP-запросе вызова инструмента; cookie не сохраняется между запросами. Не помещайте её в аргументы MCP-инструментов или в конфигурацию, доступную посторонним. Без cookie работает только `wordstat_suggest`.

Пример MCP-конфигурации:

```json
{
  "mcpServers": {
    "wordstat": {
      "type": "http",
      "url": "http://127.0.0.1:8091/mcp",
      "headers": {"X-Yandex-Cookie": "YOUR_SESSION_ID"}
    }
  }
}
```

## Инструменты

- `wordstat_top_requests(phrase, region="all")` — популярные запросы и частотность за окно по умолчанию сайта. Сайт игнорирует даты для этой таблицы.
- `wordstat_monthly_dynamics(phrase, start_date, end_date, region="all")` — помесячная динамика; даты `YYYY-MM-DD` охватывают минимум три полных месяца. Яндекс может публиковать данные с задержкой.
- `wordstat_suggest(phrase)` — поисковые подсказки без авторизации.

Wordstat использует внутренние endpoints сайта, формат и доступность которых могут измениться. Архивный планировщик и SQLite-хранилище в MCP не используются.
