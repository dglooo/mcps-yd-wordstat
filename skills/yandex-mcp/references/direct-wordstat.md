# Директ и Wordstat: справка

## Где взять Session_id для Wordstat
1. Войти в Яндекс и открыть https://wordstat.yandex.ru.
2. F12 → Application → Cookies → `.yandex.ru`.
3. Скопировать значение `Session_id`. Подходит и полная строка cookie, в ней должен быть `Session_id=`.
4. Передать: `wordstat_set_cookie(value)`. Cookie сохраняется зашифрованным, для своего ключа.

Cookie протухает после выхода из Яндекса или по требованию повторного входа. Тогда повторить шаги 1–4.
Cookie даёт доступ к аккаунту Яндекса: не публиковать и не пересылать.

## OAuth-токен Директа
- Один токен на домен. Он покрывает Директ, Метрику и Аудитории этого кабинета.
- Вносит владелец: панель управления → SEO Hub → Интеграции → карточка «Яндекс Директ»
  (домен выбирается переключателем сверху). Поле только для записи, сохранённое значение панель не показывает.
- Выпуск токена: приложение на https://oauth.yandex.ru с правами `direct:api`
  (и `metrika:read` / `metrika:write`, Аудитории, если нужны), затем
  `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ID>`.

## Права ключа (Django admin → «Права ключей»)
| Право | Что даёт |
|---|---|
| `can_use_wordstat` | все `wordstat_*` (cookie свой у каждого ключа) |
| `can_use_yandex_ads` | чтение `yd_*` |
| `can_write_yandex_ads` | запись `yd_*` (нужно и `can_use_yandex_ads`) |

По умолчанию у всех ключей все три права выключены.

## Ограничения
- `wordstat_monthly_dynamics`: даты YYYY-MM-DD, минимум 3 полных месяца. Свежий месяц Яндекс может публиковать с задержкой.
- `wordstat_top_requests` игнорирует даты: окно задаёт сам сайт Wordstat.
- Wordstat работает через внутренние запросы сайта: их формат может поменяться без предупреждения.
- `yd_audience_segment_upload` и `yd_videos_upload` выключены: они читают файлы с диска сервера.
- Запись всегда идёт через подтверждение: превью, затем `confirm=true`.
